# 📊 Productivity Analysis Based on Lifestyle Factors

This project analyzes how lifestyle habits such as sleep patterns, screen time, stress levels, and work modes impact individual productivity using Exploratory Data Analysis (EDA).

---

## 🚀 Project Overview

In today’s digital world, productivity is influenced by multiple behavioral and environmental factors. This project explores these relationships using real-world data to uncover meaningful insights.

---

## 📂 Dataset Features

- Sleep Duration  
- Screen Time (Work + Leisure)  
- Stress Levels  
- Work Mode (Remote, Hybrid, In-person)  
- Age, Gender, Occupation  
- Productivity Score (0–100)  

---

## 🛠️ Tools & Technologies

- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## 📊 Analysis & Visualizations

The following analyses were performed:

- 📈 Productivity Distribution (Histogram)  
- 📊 Occupation vs Productivity (Bar Chart)  
- 👥 Age Group Analysis  
- 💼 Work Mode Comparison (Box Plot)  
- 😴 Sleep vs Productivity (Scatter + Box Plot)  
- 🚻 Gender Analysis  
- 🔥 Correlation Heatmap  

---

## 📌 Key Insights

- Higher sleep duration improves productivity  
- Stress has a strong negative impact on performance  
- Excessive screen time reduces productivity  
- Work mode influences efficiency (Hybrid/In-person slightly better)  
- Productivity is influenced by multiple combined factors
